# gerador-cracha-js

## Objetivo
Página HTML com JavaScript que coleta nome, sobrenome, ano de
nascimento e situação de aluno, processa esses dados e mostra
um crachá virtual na console do navegador.

## Integrantes
- Dupla A:Maria Luiza Hilarino, Isabela Miguel
- Dupla B: Luann Gabriel, Ryan Lucas

## Como funciona o trabalho em equipe
- cracha-1: coleta feita pela Dupla A, geração feita pela Dupla B
- cracha-2: coleta feita pela Dupla B, geração feita pela Dupla A

## Como executar
Baixe cracha-1/index.html ou cracha-2/index.html, abra no
navegador, responda às perguntas e pressione F12 para ver a console.
